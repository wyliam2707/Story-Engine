# Campanhas

Cada pasta representa uma obra persistente. O padrão vigente para novas obras está em [Memória de Campanha](../regras-basicas/25-MEMORIA-DE-CAMPANHA.md), com o modelo em [modelos/CAMPANHA](../regras-basicas/modelos/CAMPANHA/README.md).

As histórias já existentes são testes do desenvolvimento do W4D. Seus arquivos e capítulos permanecem preservados. Não migrar, apagar ou reescrever uma obra antiga apenas para adequá-la à estrutura nova. Uma migração expressa deve conferir as fontes válidas e manter os originais.

Para criar, usar o nome e slug aprovados, verificar o destino e começar por `campanhas/<slug>/INICIO.md`. Para retomar, identificar a obra correta e ler sua entrada real, seja nova ou legada. Não escolher silenciosamente entre várias obras por recência.
