# Revisão

Esta pasta é a bancada de trabalho editorial de **Outro Céu**.

Aqui ficam prévias, planos e versões em revisão antes de um capítulo ser considerado definitivo.

## Fluxo

- `livro-pronto/` preserva o material-fonte já existente.
- `Revisao/` recebe o material que está sendo reorganizado, ampliado ou revisado.
- `Revisados/` recebe apenas capítulos aprovados como definitivos.
- PDF é gerado somente quando um bloco completo estiver aprovado em `Revisados/`.

## Regra editorial

Nada nesta pasta deve ser tratado como texto definitivo. Alterações estruturais, cortes, ampliações e redistribuições permanecem abertas até aprovação do Diretor.
