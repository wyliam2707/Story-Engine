# Capítulo 7
## Enxoval

A frase de Sara permaneceu no quarto.

**Sara -** Você sabe como revogar o contrato que acredita ter feito.

Will olhou para a marca na mão dela.

Não respondeu de imediato.

Não porque tivesse uma resposta melhor.

Porque não tinha.

**Will -** Justo.

Sara pareceu ligeiramente surpresa.

**Sara -** Só isso?

**Will -** Posso insistir que estou certo sem ter como provar. Não vejo vantagem.

Nari observou a própria aliança.

**Nari -** Finalmente uma decisão eficiente.

Will lançou um olhar para ela.

**Will -** Tenho várias.

**Sara -** Algumas delas nos trouxeram até esta conversa.

**Will -** E mantiveram vocês vivas o suficiente para tê-la.

Sara sustentou o olhar.

**Sara -** Não use isso como argumento para ganhar todas as outras.

Will ficou quieto por um instante.

Depois assentiu.

**Will -** Não vou.

A resposta encerrou aquela parte da discussão melhor do que qualquer tentativa de vencê-la teria feito.

Por alguns segundos, ninguém falou.

Então Sara percebeu que ainda segurava o cobertor contra o peito.

O casamento podia ser metafisicamente confuso.

A nudez era bastante objetiva.

**Sara -** Temos outro problema.

Will tornou a olhar para ela.

**Will -** Qual?

Sara puxou o cobertor um pouco mais para cima.

**Sara -** Estamos nuas.

Will olhou.

Nari olhou para ele.

Will tornou a olhar para o rosto de Sara.

**Will -** Sim.

Sara esperou.

**Sara -** Essa é toda a sua contribuição?

**Will -** Posso confirmar novamente, se ajudar.

Nari fechou os olhos por um segundo.

**Nari -** Não ajude.

Sara ignorou os dois.

**Sara -** Nossas roupas?

**Will -** Não sobreviveram.

**Nari -** Nenhuma parte?

**Will -** Quando encontrei vocês, havia partes de vocês que mal tinham sobrevivido.

Aquilo resolveu a pergunta.

Sara soltou o ar.

**Sara -** Certo.

Nari puxou uma pequena parte do cobertor para verificar novamente o próprio corpo.

**Nari -** Então precisamos de roupas.

**Will -** Tenho algumas.

As duas olharam para ele.

Depois uma para a outra.

Will percebeu.

**Will -** Minhas roupas.

**Sara -** Isso explica o problema no seu rosto.

**Will -** Estou calculando tamanhos.

**Nari -** Mentira.

Will olhou para ela.

**Nari -** Você já sabe que vão ficar enormes.

**Will -** Então estou calculando o tamanho do problema.

Sara apontou para a porta.

**Sara -** Vá buscar.

Will levantou.

O movimento foi mais lento do que deveria.

Nari percebeu primeiro.

**Nari -** Espere.

Ele parou.

**Nari -** Quanto gastou nos reconstruindo?

Will hesitou pouco.

**Will -** Quase toda a reserva.

Sara deixou de olhar para a porta.

**Sara -** Quase toda?

**Will -** Vocês estavam bastante destruídas.

**Sara -** Isso não responde quanto.

**Will -** O suficiente para eu não tentar sair do Éter hoje.

Nari observou a postura dele.

Agora que sabia procurar, os sinais eram fáceis de encontrar. O modo como distribuía o peso. A economia dos movimentos. A ausência daquela reserva invisível que alguém poderoso normalmente carregava até quando parado.

**Nari -** Quanto tempo?

**Will -** Para recuperar o suficiente?

**Nari -** Para tentar abrir uma passagem.

Will pensou.

**Will -** Talvez três dias.

Sara franziu a testa.

**Sara -** Talvez.

**Will -** O Éter oferece quase nenhuma energia. Posso estimar. Não posso prometer.

**Sara -** Três dias para sair?

**Will -** Três dias para tentar.

A diferença era pequena em palavras.

Não em significado.

Sara não gostou.

Nari apenas guardou.

**Nari -** Então teremos três dias.

**Will -** Provavelmente.

Sara olhou para o cobertor.

Depois para Nari.

Depois para Will.

**Sara -** Casadas com um homem sem roupas adequadas para as próprias esposas e presas com ele entre dimensões por três dias.

Will ficou olhando para ela.

**Will -** Você conseguiu deixar a situação pior quando resumiu.

**Sara -** Tenho talento.

**Will -** Percebi.

Ele foi buscar as roupas.

Quando voltou, carregava várias peças dobradas.

Sara olhou para o monte.

**Sara -** Isso é seu guarda-roupa?

**Will -** Parte dele.

Nari pegou uma das peças.

Ergueu.

A manga parecia ter intenção própria.

**Nari -** Isso cabe em duas de mim.

**Will -** Tecnicamente, não.

**Nari -** Não teste a palavra "tecnicamente" hoje.

Will recolheu a resposta antes de pronunciá-la.

Sara percebeu.

**Sara -** Está aprendendo.

Ele colocou as roupas sobre a cama.

E esperou.

Sara olhou para ele.

Will olhou para ela.

**Sara -** Vire.

**Will -** Certo.

Virou-se.

Sara soltou o cobertor apenas o necessário e tentou vestir a primeira peça.

Descobriu quase imediatamente que reconstruir um corpo não significava devolver força suficiente para usá-lo normalmente.

Erguer os braços acima dos ombros foi fácil.

Mantê-los ali não foi.

A peça caiu sobre seu rosto.

**Sara -** Merda.

Nari começou a rir.

Não muito.

O suficiente.

**Sara -** Ajude em vez de rir.

**Nari -** Estou tentando descobrir a minha.

Ela segurava uma faixa de tecido e duas amarrações com uma expressão cada vez menos favorável.

**Nari -** Will.

**Will -** Sim?

**Nari -** Como isso fecha?

Will explicou ainda de costas.

Nari olhou para a peça.

Depois para as costas dele.

**Nari -** Sua explicação foi inútil.

**Will -** É uma roupa simples.

**Nari -** Para você.

Sara finalmente retirou a peça do rosto.

**Sara -** Ele vai ter de mostrar.

Will permaneceu exatamente onde estava.

**Will -** Você mandou virar.

Sara ficou quieta.

Nari olhou para ela.

Sara olhou para Nari.

**Sara -** Certo.

Will esperou.

**Sara -** Pode olhar.

Ele virou.

E olhou.

Primeiro para a roupa presa de maneira obviamente errada no corpo de Sara.

Depois para Nari tentando descobrir qual faixa pertencia a qual lado.

Depois, inevitavelmente, para o que ainda não estava coberto.

Sara percebeu.

Nari também.

Nenhuma das duas disse nada por dois segundos.

Sara ergueu uma sobrancelha.

**Sara -** Está olhando.

**Will -** Sim.

Ela claramente esperava mais.

Não recebeu.

**Sara -** E?

**Will -** E o quê?

**Sara -** Nenhuma desculpa?

Will aproximou-se e pegou a faixa que Nari segurava.

**Will -** Não estava olhando por acidente.

Nari piscou.

Sara ficou em silêncio.

Will mostrou a posição correta da faixa.

**Will -** Passa aqui.

Nari obedeceu enquanto ainda o observava.

**Nari -** Uma honestidade curiosamente seletiva.

**Sara -** Essa parte dele parece funcionar sem esforço.

Will olhou para Sara.

**Will -** Preferiam que eu dissesse que não reparei?

Sara cruzou os braços.

A roupa quase caiu novamente.

Ela descruzou.

**Sara -** Não.

**Will -** Então pronto.

Nari conseguiu prender a primeira faixa.

**Nari -** Você parece bastante confortável olhando para duas esposas que afirma não ter pedido.

Will parou.

Olhou para ela.

Depois para Sara.

**Will -** Eu não pedi esposas.

Uma pequena pausa.

**Will -** Não disse que eram feias.

Sara encarou-o.

Nari baixou os olhos para esconder uma reação que quase virou sorriso.

Sara não teve a mesma preocupação.

**Sara -** Pelo menos sabemos que o problema não é atração.

**Will -** Nunca disse que era.

A resposta veio simples demais para ser provocação.

Isso tornou a frase mais interessante.

Nari terminou de ajustar a roupa.

**Nari -** Atração também não resolve o restante.

**Will -** Concordo.

Sara conseguiu finalmente vestir a peça superior.

Ficou grande.

Muito grande.

As mangas ultrapassavam as mãos e o tecido precisou ser preso na cintura para não transformar caminhada em acidente.

Ela olhou para si mesma.

**Sara -** Horrível.

**Will -** Funcional.

**Sara -** Essas palavras não são sinônimos.

**Will -** Hoje podem ser.

Nari estava em situação pouco melhor.

**Nari -** Precisamos adaptar isso.

**Will -** Posso cortar.

As duas olharam para ele.

**Sara -** Você sabe costurar?

**Will -** Não.

**Nari -** Então não pode cortar.

**Will -** Posso cortar muito bem.

**Nari -** E depois?

Will pensou.

**Will -** Podemos amarrar.

Sara fechou os olhos.

**Sara -** Nosso marido é incapaz de produzir uma roupa.

Will virou para ela.

**Will -** Seu marido é médico, alquimista e cultivador.

**Sara -** Nenhuma dessas coisas faz uma manga ficar no tamanho certo.

**Will -** É uma lacuna muito específica na minha formação.

Nari puxou uma manga comprida.

**Nari -** Grave.

Will levou aquilo com dignidade suficiente para não responder.

Sara voltou a observar as peças restantes.

**Sara -** Isso é tudo?

**Will -** Tenho mais.

**Sara -** Femininas?

**Will -** Não.

**Sara -** Naturalmente.

Nari olhou para o pequeno amontoado sobre a cama.

**Nari -** Tecnicamente, isso é nosso enxoval.
