# 0.3 — Consequências

Status: LEGADO / NÃO USAR COMO REGRA ATIVA

Este arquivo pertencia ao motor anterior e associava consequências a faixas de rolagem.

Essa estrutura não é canônica no sistema atual.

Consequências agora nascem de:

```text
fatos estabelecidos
estado atual
método usado
oposição legítima
limitações de Traços e Poderes
causalidade da cena
sentença do Narrador / Juiz
```

Não existe consequência automática porque uma rolagem caiu em determinada faixa, nem obrigação de acrescentar custo apenas para tornar um sucesso menos completo.

Uma consequência precisa ser sustentada pela situação que realmente aconteceu.

