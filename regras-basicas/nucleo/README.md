# Núcleo

Status: REFORMULAÇÃO ATIVA

O Núcleo define como as cadeiras compartilham autoria e como o Narrador julga a ficção.

> **A literatura não substitui julgamento; o julgamento também não precisa virar matemática quando a ficção já responde.**

## Fluxo atual

```text
DECLARAÇÃO
→ separar intenção de resultado presumido
→ identificar autoridades afetadas
→ consultar ficha, estado e continuidade
→ permitir objeção factual quando necessária
→ Narrador julga
→ abrir Mesa somente se houver dúvida ou discordância real
→ narrar
→ parar na primeira nova escolha voluntária humana
```

## Princípios atuais

```text
FICÇÃO JÁ RESPONDE
→ seguir a ficção.

INCERTEZA
→ não obriga RNG.

DISPUTA
→ não obriga RNG.

COMPARAÇÃO DIRETA
→ usar fatos e graduações pertinentes.

OBJEÇÃO SIMPLES
→ resposta simples.

DÚVIDA OU DISCORDÂNCIA REAL
→ abrir Mesa.

DIREÇÃO HUMANA EM [ ]
→ modo Diretor, fora da ficção.

NOVA ESCOLHA HUMANA
→ parar e devolver controle.
```

## Exemplo curto

```text
Corvin
→ vai para cima do Rei para mostrar quem manda.

Opositor
→ Ação impossível — o Rei é mais forte e está em melhores condições.

Narrador
→ Corvin pode avançar e lutar, mas não pode simplesmente dominá-lo nessa condição.

Jogador
→ ele vai assim mesmo.

→ continuar a cena sem criar uma rolagem apenas para simular incerteza inexistente.
```

## Regra estrutural

```text
JOGADORES
→ escrevem suas próprias peças.

OPOSITOR
→ representa resistência e fatos adversariais legítimos.

NARRADOR
→ julga coerência e causalidade.

MESA
→ alinha autoridades quando necessário.

FICHA
→ estabelece fatos, capacidades, conhecimentos e comparações.
```

## Regra final

> **O Núcleo não existe para perguntar aos dados o que autores e ficção já conseguem determinar. Ele existe para preservar autoria, estabelecer limites, resolver conflitos de autoridade e manter a história coerente enquanto várias cadeiras a escrevem juntas.**
