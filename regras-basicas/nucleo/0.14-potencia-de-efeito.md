# 0.14 — Potência de Efeito

Status: LEGADO / NÃO USAR COMO REGRA ATIVA

Este arquivo definia Potência de Execução, Potência Final e comparações matemáticas do motor anterior.

Essa estrutura não faz parte do sistema canônico atual.

A intensidade de uma capacidade é tratada atualmente pela própria descrição do Poder e, quando necessário, por graduação comparativa:

```text
[1] < [2] < [3]
```

Essa graduação:

```text
não é bônus;
não é dano;
não é dificuldade;
não é Potência de Execução;
não é multiplicador universal.
```

Ela serve para reconhecer superioridade relativa quando o mesmo aspecto realmente está sendo comparado.

Exemplo:

```text
Força Sobre-Humana [2]
contra
Força Sobre-Humana [3]

→ [3] é superior em força bruta numa comparação direta equivalente.
```

Contexto, método, Estado Atual, experiência, ambiente e limitações continuam relevantes.
