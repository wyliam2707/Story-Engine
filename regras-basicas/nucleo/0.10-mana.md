# 0.10 — Mana

Status: LEGADO / NÃO USAR COMO REGRA ATIVA

Este arquivo definia uma reserva universal de Mana e regras de gasto e recuperação no motor anterior.

Essa estrutura não faz parte do sistema canônico atual.

No sistema reformulado, uma personagem só possui custo, reserva ou limitação energética quando isso estiver legitimamente definido em sua ficha, Poder, Traço, Equipamento, Estado Atual ou outra regra canônica aprovada.

Não usar por padrão:

```text
Mana 0 / 5 / 10 por Importância
limite universal de gasto por turno
Mana para Ação / Efeito / Defesa
recuperação automática do subsistema antigo
```

Se um Poder possui limitação própria, registrar essa limitação de forma clara junto dele.

Exemplo:

```text
Poder X
[após três usos intensos, a personagem fica exausta]
```

Isso não cria uma reserva universal de Mana para as demais personagens.

A existência ou não de um novo sistema de recurso geral permanece pendente de decisão futura.
