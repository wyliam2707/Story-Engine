# Mundo

Criar arquivos por assunto somente quando fatos estruturais precisarem persistir: lugares, instituições, culturas, funcionamento do cenário, recursos e acontecimentos históricos relevantes. Registrar fonte e grau de certeza quando necessário.

Não criar uma enciclopédia por hábito. Não transformar conhecimento do executor em conhecimento das personagens. A familiaridade de uma cultura, grupo ou pessoa com algo não torna essa experiência universal. O Estado guarda condições presentes e o Livro conserva os acontecimentos completos.
